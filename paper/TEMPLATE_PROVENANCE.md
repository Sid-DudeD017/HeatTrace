## 2. Package Contents and Structure

The official ZIP archive unpacked into `sn-article-template/` containing:
* `sn-jnl.cls`: Official Springer Nature document class (Version 3.1, Dec 2024)
* `user-manual.pdf`: Springer author documentation and class manual
* `sn-article.tex`: Template sample file illustrating journal options
* `sn-bibliography.bib`: Sample bibliography file
* `bst/`: Complete directory of official Springer bibliography style files:
  - `sn-mathphys-num.bst` (Math and Physical Sciences Numbered, selected for HeatTrace)
  - `sn-mathphys-ay.bst` (Author-Year variant)
  - `sn-nature.bst` (Nature Portfolio style)
  - `sn-basic.bst` (Basic chemistry / general style)
  - `sn-aps.bst` (American Physical Society style)
  - `sn-vancouver-num.bst` / `sn-vancouver-ay.bst` (Vancouver styles)
  - `sn-apacite.bst` (APA style)
  - `sn-chicago.bst` (Chicago Humanities style)

## 3. Template Class Integrity

The official Springer class (`sn-jnl.cls`) and chosen bibliography style (`sn-mathphys-num.bst`) were copied into the working manuscript directory without modification. No class renaming, margin overriding, or font substitution was performed.
